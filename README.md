> ### АНТИВИРУСЫ И WinDivert
>
> Антивирус может отреагировать на WinDivert.  
> Этот компонент перехватывает и фильтрует трафик и потому нужен для работы zapret.
> WinDivert может применяться как безопасными, так и вредоносными программами, но сам по себе вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует WinDivert как инструмент повышенного риска или хакерское средство. В результате файл удаляется и отправляется в карантин. В таком случае обнаружение обычно называется `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). В Kaspersky, например, есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно настраиваете исключения, лучше добавить исключение; при недостаточном понимании настроек рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите Безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и укажите URL вручную. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS в параметрах самой ОС - [инструкция здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/Featherdrodepot89/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и включите пункт "Разблокировать". При распаковке через 7-Zip или PeaZip этот пункт можно не выполнять

4. Извлеките файлы в каталог, путь к которому не содержит кириллицу и специальные символы

5. Запустите необходимый скрипт
    * Для поиска подходящей стратегии: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для включения автозапуска: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск выбранной стратегии

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавить любую стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** - удалить стратегию и WinDivert из списка служб
  - **`Check Status`** - посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** - выбрать режим обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После смены значения стратегию необходимо перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** - изменить режим обработки сервисов из `ipset-all.txt`.  
  Это полезно при проверке ресурса, который без zapret работает некорректно  
  Текущее состояние указывается в скобках:
    - `none` - ни один IP не проходит проверку
    - `loaded` - IP сверяется со списком
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включить или выключить автоматический поиск обновлений
  - **`Replace active fakes`** - заменить текущий фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** - загрузить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** - вручную проверить наличие обновлений
  - **`Run Diagnostics`** - найти распространённые причины неисправности zapret.  
  В конце доступна очистка кэша <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`, что иногда возвращает неожиданно пропавшую работоспособность
  - **`Run Tests`** - открыть проверку стратегий:
    - `Standard tests` - протестировать сайты из `utils/targets.txt`
    - `DPI checkers` - проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска `general*` не появляется никакого результата

- При запуске стратегии отдельным bat-файлом, а не через service, в панели задач должен появиться winws.exe, отвечающий за обход.  
Если процесс не появился, обратитесь к [#522](https://github.com/Featherdrodepot89/zapret-discord-youtube/issues/522)

### Подходящей стратегии нет
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts окажется устаревшим, программа предложит обновить его вручную:  
  - Скопируйте содержимое открывшегося блокнота целиком
  - Через текстовый редактор с правами администратора откройте файл `hosts` в созданной папке
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что изменения действительно записались.

#### Гарантий работы нет. Если способ не помог, установите [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) и подключите [локальный прокси](https://github.com/Featherdrodepot89/tg-ws-proxy) либо любой публичный прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии могут терять работоспособность со временем.**
> Стратегия иногда работает некоторое время, а затем перестаёт из-за обнаружения используемого метода.
> В репозитории собрано много вариантов обхода. Если ни один не подходит, создайте новую конфигурацию на основе существующей и измените её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте наличие ошибок через `service.bat` -> `Run Diagnostics`

- Удостоверьтесь, что нужный ресурс добавлен в списки доменов или IP-адресов

- Испытайте другие стратегии, в том числе **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/Featherdroepot89/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вручную ресурсы и другие данные
- Перезапустите устройство
- Откройте `service.bat` -> `Remove Services`
- Выполните `service.bat` -> `Run Diagnostics`; если найдены ошибки, исправьте их и в конце выберите Y
- Удалите текущую папку zapret
- Загрузите свежий архив `zapret-discord-youtube-...` [со страницы релизов](https://github.com/Featherdrodepot89/zapret-discord-youtube/releases)
- Щёлкните по архиву ПКМ -> свойства. При наличии пункта разблокировки внизу справа включите его, затем нажмите применить и ОК
- Распакуйте архив в новую папку в корне диска, исключив пробелы и специальные символы из пути
- Запускайте разные скрипты `general` и проверяйте ресурсы. Если соединение не работает, закройте программу через значок замка в панели задач и выберите другую стратегию
- Найдя рабочую стратегию, добавьте её в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Игра или приложение перестали работать при включённом zapret

- В `service.bat` проверьте, что `Game Filter` установлен в **`disabled`**, а `IPSet Filter` - в **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о проблеме с WinDivert

- Откройте инструкцию по ссылке: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS настроен](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно противодействовать таким расширениям.
- Переберите остальные стратегии, особенно если раньше соединение работало.
- Также смотрите [#251](https://github.com/Featherdrodepot89/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS включён](#%EF%B8%8Fиспользование)
- Сначала определите стратегию, на которой открывается YouTube, и запустите её
- В `service.bat` откройте `Run Diagnostics` и очистите там кэш Discord
- Проверьте приложение Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если браузерная версия работает, временно используйте её
- Если браузер тоже не подключается, повторите проверку всех стратегий: YouTube и Discord могут работать на разных вариантах
- Обсуждение проблемы находится в [#252](https://github.com/Featherdrodepot89/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Featherdrodepot89/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Игры не подключаются

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Обычно стоит выполнить следующие действия:
- через `service.bat` обновить ipset и включить `Game Filter`
- если это не решило проблему, дополнительно включить `ipset any`

Учтите: `ipset any` способен нарушить открытие многих сайтов. Не держите этот режим включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если результат отсутствует, создайте обсуждение в разделе [Discussions](https://github.com/Featherdrodepot89/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Нужного ответа нет в списке

- Опишите проблему [здесь](https://github.com/Featherdrodepot89/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные ресурсы для обхода можно указать в следующих файлах:
- **`list-general-user.txt`** - домены; поддомены будут учтены автоматически
- **`list-exclude-user.txt`** - домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
